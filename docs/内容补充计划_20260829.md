## 二、补充计划

### P0 · 本周（技术性修补，半天）

| 任务 | 产出 | 说明 |
|---|---|---|
| sitemap 自动生成脚本 | scripts/gen-sitemap.mjs | 从 reviews/saas/articles/compare/news/categories 文件清单 + 根页面自动生成 114+10 URL，以后每次批量部署前跑一次 |
| marketing 分类页 | categories/marketing.html | 复用现有分类页模板，聚合 4 个 marketing 工具 |
| 新 10 篇新闻补进 sitemap | sitemap.xml 124 URL | 与上一条一起批量部署 |
| 分类页↔category 枚举对齐 | 数据一致性 | writing→chat 或新增 writing 类别，二选一定死 |

### P1 · 月度节奏（内容生产线，每月目标）

| 项 | 月增量 | 执行方式 |
|---|---|---|
| 新闻 | +16~20 条（每周 4-5 条） | 现有管线：选题搜索→写作（含媒体评价）→ gen-image 配图→ 后台 API 入库→ 批量部署；每月月底跑一次 sitemap 脚本 |
| 新工具入库 | +8~12 个（57→100，约 4 个月） | 后台"工具管理"直接录入（名称/分类/评分/评测链接）；优先补 audio（3→8）和 marketing（4→10）；新品评测页随工具一起建 |
| 词汇表 | +15 词/月（14→50+） | 每词 100-150 词定义 + 站内交叉链接（指向相关工具/文章），LLM 抓取友好 |
| 首页精选 | 维持 8 个 | 随新工具评分滚动更新 |

### P2 · 季度目标（板块补强）

| 项 | 季末目标 | 优先理由 |
|---|---|---|
| 对比页 | 6 → 15-20 | "X vs Y" 是高转化搜索词；从工具库里两两组合热门对 |
| SaaS 评测 | 19 → 28 | 39:19 失衡；SaaS 词竞争小、商业价值高 |
| 指南/榜单 | 17 → 25 | "best AI tools for X" 长尾矩阵，每篇内链 8-10 个评测页 |
| Deals | 9 → 25-30 | 真实在售优惠（affiliate 潜力），每周核对时效 |
| Weekly 期刊 | 每月 2 期 | 内容=当月新闻精选+1 篇深度+1 个工具推荐；沉淀归档页（SEO 复用） |
| Courses | 决策：填内容或下线入口 | 免费课→引流指南文章；付费课→暂不做。建议改为"学习路径"聚合页 |

### 内容标准（所有新增内容统一遵守）

1. 配图：gen-image 生成，明亮/温馨/写实，无大面积黑色，屏幕浅色主题，场景贴合内容（已有规范）
2. 每篇评测/文章 ≥3 个站内交叉链接（评测↔对比↔分类↔词汇表）
3. 新闻带"Media & industry reaction"引述区（格式已定）
4. 事实性内容必须有信源；引述不编造直引语录
5. 每次批量部署前：跑 sitemap 脚本 + llms.txt 核对 + 全站链接抽查

### 执行节奏（配合"本地测试→批量上传"流程）

- **每周一次**内容批量：当周新闻 + 新工具 + 词汇表更新 → 本地预览 → 确认 → 统一部署
- **每月一次**盘点：更新本计划的数字，检查 sitemap/llms.txt/内链健康度
