Content Production Standards Overview

全站 7 个内容频道的产出标准总览。每个频道有独立的页面结构、写作规范、评分体系、SEO 要求和质量检查清单。

通用标准

图片 — gen-image skill，明亮/温馨/写实，无大面积黑色，浅色屏幕，1536×1024，压缩 ≤ 200KB JPEG
SEO — canonical + OG + JSON-LD 三件套 + sitemap + IndexNow
E-E-A-T — 测试方法论 + 联盟披露 + 无供应商关系 + 60-90 天复测 + Evidence > Adjectives
部署 — 本地构建 → 用户预览 → 确认 → gen-sitemap → 单次 deploy → 单次 push

SaaS Review

/saas/{slug}-review.html · 34 篇 · 全部 v2 详细版

字数 ≥ 1,500配图 1FAQ ≥ 5JSON-LD 3内链 ≥ 4

Required Sections

  • Review Hero (eyebrow + h1 + hero image + subtitle + meta)
  • Quick Verdict box
  • Facts Grid (6 items incl. Our Score)
  • Affiliate Disclosure
  • What is [Tool]?
  • How We Tested (specific bullet list)
  • Score Breakdown: 5 Dimensions (dim-table)
  • What We Loved (Pros / Cons grid)
  • Performance in Daily Use DEEP-DIVE
  • Integrations & Ecosystem DEEP-DIVE
  • Support & Documentation DEEP-DIVE
  • Pricing (tiered list + note)
  • Who Should Use It / Not Ideal For
  • Final Verdict (verdict-box)
  • Comparison Table (vs 3-4)
  • FAQ (≥ 5, JSON-LD synced)

5-Dimension Scoring

Quality of Output — 核心功能产出质量
Ease of Use — 上手难度 / UI / 新用户效率
Value for Money — 每 1 美元产出价值 / 免费层
Speed & Reliability — 延迟 / 稳定 / 一致性
Support & Docs — 文档 / 社区 / 官方支持

总分 = 5 维加权，每维必须有 Notes

✅ Checklist

  • dim-table 5 维有 Notes
  • FAQ 可见 = JSON-LD（≥5）
  • 3 组 JSON-LD
  • Disclosure 在页顶
  • 价格标注 as-of 日期
  • 对比表 ≥ 3 竞品
  • 内链 ≥ 4
  • 字数 ≥ 1,500

News Article (v2 Editorial)

/news/{slug}.html · 30 篇 · 全部 v2 版式

字数 600-1,000配图 1+1媒体评价 ≥ 2

Required Sections (v2)

  • Page Hero (crumbs + tag + when + h1)
  • News Deck (1-2 sentence hook)
  • Byline (StackHK News Desk · date)
  • Hero Image
  • Lead paragraph (1-2 sentences factual)
  • What's Happening (1-2 short paras)
  • Why It Matters (1-2 short paras)
  • Punch Line (bold standalone sentence)
  • Media & Industry Reaction (quote cards × 2-3)

Writing Style (v2)

Deck: 1-2 句钩子，有立场的开场白（不是摘要）
段落: 每段 1-3 句
Punch Line: 单句独立段，加粗放大
媒体评价: 来源必须是真实媒体报道或官方公告

✅ Checklist

  • Deck 存在
  • ≥ 2 条媒体评价
  • Punch Line 存在
  • 配图 hero + thumb
  • KV 已入库
  • 不与已有 30 篇重复

Universal Standards

Image Generation

Pipeline: gen-image skill → sharp compression (mozjpeg q82) → site images/
Style: 明亮/温馨/写实，无大面积黑色，浅色屏幕
Size: 1536×1024 → JPEG ≤ 200KB
Prompt: 场景 + 光线 + 氛围 + "realistic photography, no dark areas"

SEO

Title: [Topic] (2026): [Descriptor] | StackHK
Meta: 150-160 chars
Canonical: 每页必须
JSON-LD: Article/Review + FAQPage + BreadcrumbList
Sitemap: 每次部署前跑 gen-sitemap.mjs
IndexNow: git push 自动

E-E-A-T

Experience: 具体 Testing Process
Expertise: 评分有 Notes、对比有数据
Authoritativeness: 独立声明
Trustworthiness: 联盟披露页顶 + 价格 as-of + 失败案例 + 复测承诺

Internal Linking

每篇 ≥ 4 个交叉链接。Topic Cluster: 主页面(pillar) ↔ 子页面互链。
