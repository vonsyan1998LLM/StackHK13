ChatGPT Work Gets an Admin Plugin — and Enterprise IT Breathes Easier

OpenAI just gave IT departments a control plane for ChatGPT Work and Codex. The AI land-grab has officially moved to the admin console.

StackHK News Desk·Updated Aug 26, 2026

On August 26, OpenAI shipped an Admin plugin for ChatGPT Work and Codex: one place to govern seats, data boundaries and agent permissions across an entire company.

What’s Happening

Instead of per-seat settings scattered across consoles, administrators now manage workspace access, connectors and Codex agent behavior centrally.

The rollout lands as ChatGPT Work shifts from experiment to standard workplace infrastructure — and as every rival courts the same buyer.

Why It Matters

Anthropic added Inference Hooks for Claude Enterprise in early August. Workspace suites ship AI governance layers by default.

OpenAI’s answer is to make administration a first-class surface rather than a settings page.

Whoever makes agents governable makes them deployable.
