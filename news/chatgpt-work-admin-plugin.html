OpenAI ships an Admin plugin for ChatGPT Work and Codex

OpenAI introduced an Admin plugin for ChatGPT Work and Codex on August 26, giving IT departments a single control plane for seats, data boundaries and agent permissions.

The plugin arrives as ChatGPT Work shifts from an experiment to standard workplace infrastructure. Instead of per-seat settings scattered across consoles, administrators can now govern workspace access, connectors and Codex agent behavior from one place — the kind of plumbing enterprises demand before rolling AI out company-wide.

The timing is no accident. Rival assistants have spent the summer courting the same buyer: Anthropic added Inference Hooks for Claude Enterprise in early August, and every major workspace suite now ships an AI governance layer. OpenAI’s answer is to make administration a first-class surface rather than a settings page.
